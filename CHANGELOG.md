# Changelog

## 0.1.0-cad-preview — 2026-09-11

First public development snapshot of the R05 design.

- Original parametric CAD source, a public mechanical FreeCAD model and a printed-part STEP.
- Fourteen robot print parts and two fit coupons in STL and 3MF.
- Local CAD viewer with assembly, exploded and parts views, part downloads and four joint controls.
- Original mascot, actual CAD renders, contribution guidance and a staged hardware/simulation roadmap.
- Local reference downloader with source hashes and explicit license boundaries.
- Automated file, mesh, viewer and simulation source checks.

This is a **prerelease for design review**. Physical fit, powered assembly, walking and Isaac runtime/training have not been demonstrated. The public preview omits four supplier board geometries; the complete intended physical assembly still requires those components. See the [engineering review](docs/engineering-review.md) before printing or purchasing parts.
