# Parts and power references

The maintained component list and reference dimensions are in the [BOM](bom.md). It identifies the exact selected PCB products, camera/servo uncertainties and the proposed power architecture.

Use [hardware measurements](hardware-measurements.md) for actual batch dimensions and electrical observations. Nominal vendor data and CAD assumptions must not be entered as physical test results. The [reference input guide](../references/README.md) documents the four hashed CAD inputs and upstream notices needed for a local rebuild.
